# Code of Conduct

ActionSeam is a technical community project. Participation should make it easier for people to inspect evidence, challenge assumptions, reproduce findings, and improve software together.

## Expected behavior

- discuss code and evidence rather than attacking people;
- distinguish reproducible findings from speculation;
- welcome corrections and good-faith disagreement;
- avoid harassment, discrimination, threats, or targeted humiliation;
- respect responsible-disclosure requests for potentially sensitive findings.

## Unacceptable behavior

Harassment, discriminatory abuse, sexual harassment, doxxing, threats, deliberate intimidation, and sustained personal attacks are not acceptable in project spaces.

## Enforcement

Project maintainers may edit/remove content, lock discussions, reject contributions, or restrict participation when needed to protect the community and project integrity.

For conduct concerns that should not be public, contact the project maintainer privately using the contact channel listed in [`SUPPORT.md`](./SUPPORT.md).
