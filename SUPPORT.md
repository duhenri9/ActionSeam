# Support

ActionSeam is experimental and currently has no commercial support commitment.

Use GitHub Issues for:

- reproducible bugs;
- profile proposals;
- adapter compatibility work;
- documentation problems;
- counterexample improvements.

Use the repository security reporting path for sensitive vulnerabilities.

When asking for help, include:

- ActionSeam commit/version;
- Node version;
- subject/runtime/action-target version;
- profile id;
- reproduction command;
- report/counterexample with secrets removed.
